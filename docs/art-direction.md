# Art Direction

This is the shared studio direction, not a requirement that every game look the same.

## Studio-level principles

- Strong composition and readable silhouettes.
- Deliberate color and lighting choices.
- A small number of memorable moments is better than a large amount of generic content.
- Interface elements should support the experience without obscuring it.
- Performance is part of polish.

## Game-level override

Every game may replace these principles with its own art-direction document. A game-specific decision wins over this shared document.
