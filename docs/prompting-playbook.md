# Prompting Playbook

The repository is designed for plain-language collaboration. A useful request can include any of the following:

- What the player should feel
- What the player should do
- What the player should see or hear
- A reference or contrast
- The intended audience and play session length
- Whether the request applies to one game or the shared foundation

## Scope rule

When a request is game-specific, change only that game's directory unless a shared abstraction is clearly justified. When a request should affect every game, update the shared package and document the migration impact.

## Iteration rule

Prefer a playable, inspectable change over a speculative architecture. Build the smallest version that lets us judge the idea, then deepen it through successive prompts.
